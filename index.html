About

I’m not really one thing.

My background is in sales and e-commerce operations, but I keep drifting into product, data, automation, and code whenever I see something that could work better.

NOT A DEVELOPER-FIRST STORY

I didn’t start by learning code and then looking for things to build. It was the opposite. Work kept giving me annoying problems, so I learned enough code to solve them.

Sometimes the answer is a formula. Sometimes it is Apps Script. Sometimes it becomes a Cloudflare Worker, an Android app, or a whole product. I care more about whether it works than whether the stack sounds impressive.

01Understand what is actually annoying.
02Build the smallest useful version first.
03Then fix what breaks in real use.
