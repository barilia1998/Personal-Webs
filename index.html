About me

I didn’t start with code.

I started in sales and marketplace operations. Then spreadsheets got complicated, reporting got slow, and repetitive work kept piling up.

So I learned enough formulas to fix one problem. Then Apps Script for another. Then JavaScript, Cloudflare, Android, and whatever else the next problem needed.

I still don’t think of myself as “a developer first.” I’m more interested in understanding how work actually happens, then making it less annoying.
